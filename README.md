# KrathokKidsBit

บล็อกภาษาไทยสำหรับหุ่นยนต์ KidsBIT + จอ OLED 1.3 นิ้ว สำหรับนักเรียน ป.4-ป.6

พัฒนาต่อจาก [pxt-kidsbit-vx](https://github.com/pt-robotics/pxt-kidsbit-vx) ของ PT-BOT (MIT License)

powered by micro:bit

![PTKidsBIT](https://raw.githubusercontent.com/pt-robotics/pxt-kidsbit-vx/master/big_icon.png)

The package adds support [PTKidsBIT](https://ptbot.medium.com/pt-bot-kidsbit-aa923a5caeaa) board from [PT-BOT](https://web.facebook.com/LPRobotics).

## micro:bit Pin Assignment

* ``P0``  -- Connected to Buzzer
* ``P1``  -- Digital Input/Output and Analog Input/Output
* ``P2``  -- Digital Input/Output and Analog Input/Output
* ``P13`` -- DigitalWrite Pin for DC motor control direction 1
* ``P14`` -- AnalogWrite Pin for DC motor speed control 1
* ``P15`` -- DigitalWrite Pin for DC motor control direction 2
* ``P16`` -- AnalogWrite Pin for DC motor speed control 2
* ``P19`` -- SCL connected to I2C-based ADC chip and OLED
* ``P20`` -- SDA connected to I2C-based ADC chip and OLED

### ตัวอย่าง: ไปทางแยกที่ 2 แล้วเลี้ยวซ้าย

```blocks
KrathokKidsBit.oledInit(OLED_Address.Addr_0x3C, true)
KrathokKidsBit.lineTuning(Kids_Band.All, 0.02, 0.02)
KrathokKidsBit.lineReading(50, 120)
KrathokKidsBit.setSensorCal([929, 1667, 1514, 1362, 1273, 969, 595, 558], [3724, 3833, 3829, 3830, 3814, 3782, 2312, 2450])
KrathokKidsBit.waitForButton(Kids_Button.A)
basic.forever(function () {
    KrathokKidsBit.lineToJunction(Kids_Junction.Center, 2, 80, Kids_Then.TurnLeft, 50)
    KrathokKidsBit.haltAll()
})
```

### ตัวอย่าง: หลบสิ่งกีดขวาง

```blocks
basic.forever(function () {
    KrathokKidsBit.oledShowLine("Distance = " + KrathokKidsBit.kidsDistance(), 1)
    if (KrathokKidsBit.kidsObstacle(15)) {
        KrathokKidsBit.robotMove(Kids_Move.Backward, 50, 0.5)
        KrathokKidsBit.robotSpinDegrees(Kids_LeftRight.Right, 90, 60)
    } else {
        KrathokKidsBit.robotMove(Kids_Move.Forward, 50)
    }
})
```

## หยุดทำงานทั้งหมด

`หุ่นยนต์หยุด` แค่หยุดมอเตอร์ บล็อกอื่นสั่งให้วิ่งต่อได้ทันที ส่วน `หยุดทำงานทั้งหมด` **หยุดถาวร** จนกว่าจะกดปุ่มรีเซทหรือปิดเปิดเครื่องใหม่

```blocks
input.onButtonPressed(Button.AB, function () {
    KrathokKidsBit.haltAll()
})
KrathokKidsBit.lineFollowForever(40)
```

| สิ่งที่ถูกหยุด | วิธี |
|---|---|
| มอเตอร์ล้อ | บังคับความเร็วเป็น 0 ทุกครั้งที่ถูกเรียก |
| เซอร์โว | ไม่รับคำสั่งอีก แขนค้างท่าเดิม ไม่สะบัด |
| ลูปเกาะเส้นและลูปหมุนที่ค้างอยู่ | ออกจากลูปเอง |

จอ micro:bit ขึ้น `STOP` แล้วค้างเครื่องหมายกากบาท จอ OLED ขึ้น `press RESET`

## เซ็นเซอร์เดินตามเส้น

ผังเซ็นเซอร์ตรงกับ **PTKidsBIT Education Robot Kit** บล็อกเดินตามเส้นตั้งค่าให้เองอัตโนมัติ:

```
   ซ้าย ───────────────────────────────► ขวา

   [6]   [0] [1] [2] [3] [4] [5]   [7]
    ▲    └───── กลาง 6 ตัว ─────┘    ▲
  ทางแยกซ้าย                    ทางแยกขวา
```

- เซ็นเซอร์กลาง 6 ตัวใช้คำนวณตำแหน่งเส้น (0-5000 ศูนย์กลาง 2500) ป้อนให้ PID
- เซ็นเซอร์ซ้าย/ขวาใช้ตรวจทางแยก

### สอนเซ็นเซอร์

`สอนเซ็นเซอร์ แบบ _`

| แบบ | วิธีทำ |
|---|---|
| **ลากผ่านเส้น** (แนะนำ) | กดปุ่ม A แล้วลากหุ่นกลับไปกลับมาข้ามเส้นตลอดเวลา จนได้ยินเสียงสูง 2 ครั้ง กด ⊕ ปรับเวลาลากได้ (ตั้งต้น 8 วินาที) |
| **วางทีละจุด** | เสียงปี๊บ → วางบนเส้น กดปุ่ม A → วางบนพื้น กดปุ่ม A → เสียงสูง 2 ครั้ง = ผ่าน |

เสียงต่ำ 2 ครั้ง = ไม่ผ่าน แบบลากจะวิ่งข้อความ `FAIL 6 7` บอกเลขช่องที่พลาด ช่องที่ไม่ผ่านจะคงค่าเดิมไว้

**วิธีลากให้ผ่าน:** ลากให้กว้างพอที่เซ็นเซอร์**ทุกตัว**ผ่านเส้น รวมเซ็นเซอร์ทางแยกด้วย ลากต่อเนื่องจนจบ และส่ายให้กว้างกว่าเส้นพอสมควร (หุ่นใช้ข้อนี้ตัดสินว่าด้านไหนคือพื้น จึงใช้ได้ทั้งเส้นดำบนพื้นขาวและเส้นขาวบนพื้นดำ)

### ใส่ค่าคาลิเบรตเอง ไม่ต้องสอนทุกครั้ง

สอนเซ็นเซอร์หนึ่งครั้ง แล้วดูค่าด้วย `จอ OLED แสดง ค่าคาลิเบรต`:

```
CH LINE  GND
 0  929 3724
 1 1667 3833
 ...
```

เอาคอลัมน์ `LINE` ใส่ช่อง **บนเส้น** และคอลัมน์ `GND` ใส่ช่อง **บนพื้น** เรียงช่อง 0 ถึง 7:

```blocks
KrathokKidsBit.setSensorCal([929, 1667, 1514, 1362, 1273, 969, 595, 558], [3724, 3833, 3829, 3830, 3814, 3782, 2312, 2450])
```

| หมายเหตุ | |
|---|---|
| ค่าที่ใส่ | 0-4095 (นอกช่วงนี้จะถูกตัดให้อยู่ในช่วง) |
| จำนวนค่า | สองลิสต์ต้องยาวเท่ากัน ใส่น้อยกว่า 8 ตัวได้ ช่องที่ไม่ใส่จะคงค่าเดิม ถ้ายาวไม่เท่ากันจะมีเสียงเตือน |
| ใส่ค่าเท่ากันทั้งคู่ | ระบบถ่างให้ 1 หน่วยกันหารด้วยศูนย์ แต่เซ็นเซอร์ตัวนั้นจะแยกเส้นกับพื้นไม่ออก |

### ปรับการอ่านเส้น (แก้อาการเข้าโค้งกระตุก)

`ปรับการอ่านเส้น ความนุ่ม _ เกณฑ์เห็นเส้น _`

- **ความนุ่ม** (0-95 ตั้งต้น 50) ตำแหน่งเส้นกระโดดเป็นขั้นทุกครั้งที่เซ็นเซอร์เข้าหรือออกจากเกณฑ์ ค่า D จึงเป็นหนาม หุ่นเลยปล่อยแล้วกระชากสลับกัน ค่านี้กรองหนามลง แนะนำ 40-70 มากไปหุ่นจะตอบสนองช้าและเริ่มส่าย
- **เกณฑ์เห็นเส้น** (10-900 ตั้งต้น 200) ค่าต่ำ (80-120) นับเซ็นเซอร์ที่เห็นขอบเส้นด้วย ตำแหน่งจึงเปลี่ยนต่อเนื่องกว่า แต่ต่ำเกินไปจะไวต่อคราบสกปรก

### ความไว KP / KD และจูนอัตโนมัติ

ความไวแยกตามช่วงความเร็ว หุ่นหยิบค่าของช่วงที่ตรงกับความเร็วที่สั่งไปใช้เอง

| ช่วง | ความเร็ว |
|---|---|
| ช้า | 0-40 |
| กลาง | 41-60 |
| เร็ว | 61-100 |

`ปรับความไว ช่วง ทุกช่วง` ตั้งให้เหมือนกันทั้งสามช่วงในทีเดียว ค่าตั้งต้นคือ KP 0.05 KD 0.1

`จูนอัตโนมัติ ความเร็ว _` ไล่หาค่าให้เองครบสามขั้น (หา KP → หา KD → หา KP ซ้ำ) และหุบช่วงลงทุกรอบจนผลต่างอยู่ในระดับ noise ผลลงช่วงที่ตรงกับความเร็วที่ทดสอบ **จูนที่ความเร็วเท่าไรก็ได้ช่วงนั้น**

```blocks
KrathokKidsBit.lineCalibrate(Kids_CalMode.Sweep)
KrathokKidsBit.lineAutoTune(80, 2)
```

| ปุ่ม | ใช้ตอนไหน |
|---|---|
| **B** | เริ่มจูน (จอ micro:bit กะพริบลูกศรชี้ไปที่ปุ่ม B) |
| **A** | วางหุ่นกลับบนเส้นแล้วไปต่อ กดเฉพาะตอนหลุดเส้น ถ้าหุ่นยังคร่อมเส้นจะวิ่งต่อเอง |

จบแล้วจะค้างหน้าสรุปไว้จนกว่าจะกดปุ่ม A และส่งบรรทัดที่ก๊อปไปวางในโหมด JavaScript ได้ทางสาย USB:

```
>>> COPY THIS LINE INTO YOUR PROGRAM:
KrathokKidsBit.lineTuning(Kids_Band.Fast, 0.14, 4.00)
```

ถ้าขึ้น `CANNOT TUNE` หรือ `AUTO TUNE FAILED` แปลว่าวัดอะไรไม่ได้ (ยังไม่ได้สอนเซ็นเซอร์ หุ่นไม่ขยับ หรือไม่ได้อยู่บนเส้น) ค่าเดิมจะไม่ถูกเขียนทับ

### เลี้ยวหาเส้น

`เลี้ยว ซ้าย/ขวา จนเจอเส้น` หมุนเร็วจนเซ็นเซอร์ด้านที่หันไปเห็นเส้นใหม่ แล้วค่อย ๆ ช้าลงเมื่อเส้นเข้าใกล้กลาง หยุดตรงตำแหน่งเส้น (ไม่ใช่เซ็นเซอร์ตัวเดียว) แล้วเบรกและขยับแก้ให้ตรง ถ้าหาเส้นไม่เจอใน 4 วินาทีจะหยุดเอง

## ดูค่าเซ็นเซอร์บนจอ OLED

`จอ OLED แสดง _` เลือกแบบได้ 5 แบบ แบบที่เป็นค่าสดให้วางใน `วนซ้ำตลอดไป`

| แบบ | แสดงอะไร |
|---|---|
| ค่าเซ็นเซอร์เส้น | ค่าดิบของเซ็นเซอร์ซ้าย/กลาง/ขวา, % ที่แปลงแล้ว (100 = บนเส้น) และตำแหน่งเส้น |
| กราฟแท่งเซ็นเซอร์เส้น | แท่งเรียงตามตำแหน่งจริงซ้าย→ขวา ยิ่งสูงยิ่งเห็นเส้นชัด แถบทึบ = อยู่บนเส้น |
| ค่าเซ็นเซอร์รายช่อง | ค่าดิบพร้อมหมายเลขช่อง `CH0` ถึง `CH7` |
| ค่าคาลิเบรต | ค่าที่**เก็บไว้**ของทุกช่อง (`-` = ยังไม่ได้สอน) ใช้จดไปใส่ `ตั้งค่าเซ็นเซอร์` |
| ตรวจสอบฮาร์ดแวร์ | หาชิป ADC / มอเตอร์ / จอ และค่าดิบทั้ง 8 ช่อง ส่งออกทางสาย USB ด้วย จึงใช้ได้แม้ไม่มีจอ |

ถ้าค่าดิบที่อ่านสด ๆ อยู่นอกช่วงค่าคาลิเบรตทุกตัว ตำแหน่งเส้นจะนิ่งตลอดและจูนอัตโนมัติจะหาค่าไม่ได้ ให้สอนเซ็นเซอร์ใหม่

### บอร์ด KidsBIT มี ADC สองรุ่น

| รุ่น | ที่อยู่ I2C | ช่วงค่า |
| --- | --- | --- |
| เดิม (ADS7828) | `0x48` | **0-4095** |
| ใหม่ | `0x49` | **0-255** |

ส่วนขยายนี้ตรวจรุ่นให้เองตอนอ่านค่าครั้งแรก ค่าคาลิเบรตของสองรุ่นใช้แทนกันไม่ได้ ถ้าเปลี่ยนบอร์ดต้องสอนเซ็นเซอร์ใหม่

## รอให้กดก่อนเริ่ม

`รอกด _` หยุดรอจนกดแล้วปล่อย ใช้เป็นจุดเริ่มของโปรแกรม จะได้วางหุ่นให้เรียบร้อยก่อน เลือกได้ `A` `B` `A+B` และ `สัมผัสโลโก้` (เฉพาะ micro:bit V2) กด ⊕ เพื่อเลือกไอคอนระหว่างรอและหลังกด

วาดไอคอนครั้งเดียวแล้วเช็คปุ่มทุก 20 ms กดสั้น ๆ ก็ไม่หลุด และรอจนปล่อยมือก่อน จึงวางบล็อก `รอกด` เรียงกันหลายตัวได้

## แขนและก้ามหนีบ

ตั้งค่าครั้งเดียวตอนเริ่ม แล้วสั่งด้วยบล็อก `แขนกล _`

```blocks
KrathokKidsBit.armSetup(Kids_Servo.S0, 175, 5, Kids_Servo.S1, 90, 20)
input.onButtonPressed(Button.A, function () {
    KrathokKidsBit.armDo(Kids_ArmAction.GripAndLift)
})
input.onButtonPressed(Button.B, function () {
    KrathokKidsBit.armDo(Kids_ArmAction.PlaceAndRelease)
})
```

| ท่า | ทำอะไร |
|---|---|
| `จับแล้วยก` | อ้าก้าม → ลดแขน → หนีบ → ยกแขน (อ้าก่อนลด จะได้ไม่ชนของ) |
| `วางแล้วปล่อย` | ลดแขน → อ้าก้าม → ยกแขน (ลดก่อนปล่อย จะได้ไม่ทิ้งของจากที่สูง) |
| `อ้าก้าม` `หนีบ` `ยกแขน` `ลดแขน` | สั่งทีละอย่าง เวลาต้องการลำดับเอง |

กด ⊕ ที่ `ตั้งค่าแขนกล` เพื่อตั้งเวลารอต่อหนึ่งท่า (ตั้งต้น 400 ms) แขนหนักหรือขยับไกลให้เพิ่ม

> ⚠️ ค่าก้าม (ช่อง 1 เปิด 175 หนีบ 5) อ้างจากชุด PT KidsBIT ส่วนมุมแขนเป็นค่ากลาง ๆ ลองทีละมุมด้วย `เซอร์โวช่อง _ หมุนไปที่ _ องศา` ก่อนแล้วค่อยเอาเลขมาใส่

## OLED 1.3 inch (SH1106 128x64 I2C)

Ported from Adafruit_SH110X (`Adafruit_SH1106G`) with the Adafruit GFX 5x7 font (English letters and numbers only).

Wiring: `VCC` → 3V3, `GND` → GND, `SCL` → P19, `SDA` → P20 (I2C address 0x3C, or 0x3D)

```blocks
KrathokKidsBit.oledInit(OLED_Address.Addr_0x3C)
KrathokKidsBit.oledShowLine("KrathokKidsBit", 1)
basic.forever(function () {
    KrathokKidsBit.oledShowLine("ADC0 = " + KrathokKidsBit.kidsSensor(Kids_Sensor.ADC0), 3)
})
```

ถ้าติดตั้งจอกลับหัว กด ⊕ ที่ `เริ่มใช้จอ OLED` แล้วเปิด `หมุนจอ 180 องศา`

Tip (จอ OLED > เริ่มต้นจอ): turn `อัปเดตทันที` OFF, draw several shapes, then use `แสดงภาพที่วาด` once for faster drawing without flicker.
